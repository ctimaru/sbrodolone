# Sbrodolone

Sito web statico per la pizzeria d'asporto Sbrodolone.

## Pubblicazione con GitHub Pages

1. Aprire **Settings → Pages** nella repo.
2. In **Build and deployment**, selezionare **Deploy from a branch**.
3. Scegliere il branch `main` e la cartella `/ (root)`.
4. Salvare e attendere la pubblicazione.

Il pulsante del menu utilizza l'integrazione GloriaFood fornita dalla pizzeria.
